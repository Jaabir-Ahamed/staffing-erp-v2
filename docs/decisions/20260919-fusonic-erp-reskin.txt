Fusonic / rona:systems ERP reskin (visual only)

Follows https://www.fusonic.net/en/work/style-guide-erp-software.
No query, RLS, route, or computeTimesheet changes.

Styling system: Tailwind v4 + existing shadcn CSS variables in
app/globals.css. Tokens were added there rather than introducing a
second styling approach.

Typography
  Font: Public Sans (next/font/google, OFL), chosen in the guide for
  small-size table readability.
  Scale (size / weight / line-height):
    page title     22px / 600 / 28px  (.type-page)
    section header 16px / 600 / 24px  (.type-section)
    table header   11px / 600 / 16px  (.type-table, uppercase)
    body           13px / 400 / 20px  (.type-body)
    helper / meta  12px / 400 / 16px  (.type-meta)
  Nav and inline Fluent icons are 20px and 16px respectively.

Component states (buttons, nav, badges, inputs)
  default / hover / focus / disabled are defined on .ui-control,
  .ui-nav, and button/badge variants. Active nav uses primary tint
  plus primary text, not a new color per route.

Icons
  @fluentui/react-icons 2.0.341 — Microsoft Fluent UI System Icons,
  Regular (outline) weight.

Needs Attention structure
  All five flag types share a .resolve-panel (left warning rule,
  label, control, Save). missing_client_lookup uses a native select
  of the 10 clients plus Save on one row so the 301-row queue is
  scannable; worker matching still uses SearchSelect because the
  worker list is large.
